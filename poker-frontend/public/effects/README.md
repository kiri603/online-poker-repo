# 牌桌演出资源

铁骑与南蛮入侵由 `battleTroops.js` 的 Pixi Graphics 分部件绘制，使用统一暖白色线条，不填色。铁骑以前景将军挥戈下令开场，戈从上向下挥出后指向敌阵，再带领三层错列队形加速横向冲撞。骑手在起跑前压低重心，冲锋时身体前倾，马腿、马头、披风和装备分别运动，速度线与尘线在下令后出现。八名骑手分别配有长枪、刀、弓、军旗、刀盾或戟，头盔、披风、马鬃及马鞍纹样也各有区别，精简模式保留将军及四种士兵。动作与位移共享 `getCavalryMotion` 时间线，确保挥戈完成后才冲刺。

南蛮入侵按用户示意图采用朝右的大象侧面特写，背上有举刀蛮人，前脚附近安排两名步战蛮人。象身使用长躯干、单侧大耳、前伸象牙和卷鼻轮廓。大象在前段抬高前脚并停顿蓄力，中段快速踩下，落地后回弹；象背骑手随象身起伏，步战蛮人站地挥斩，砍刀均跟随肩、肘和手的关节运动，弧形刃口迎着下挥方向。`battleTroops.test.mjs` 检查骑手及两名步兵的刀尖运动与刃口朝向一致。地面尘线与压力波在落脚后出现，短暂抖动只作用于特效层。两项均不加载生成的军阵图片。

`airplane.png`、`explosion.png` 使用内置 image_gen 工具新建，透明背景；提示词见 [image-prompts.json](./image-prompts.json)。飞机使用独立三机编队；火焰按每次爆破独立扩张、上升和淡出。PNG 原稿和停用的军阵图片保存于 `poker-frontend/asset-sources/effects/`，不复制进生产构建。游戏仅加载飞机与火焰的 `.webp` 发布版，使用 FFmpeg `libwebp` 编码，质量 90、压缩级别 6，保留透明度。

炸弹弹体、引信、碎片、烟尘、弓箭、盾牌、剑和星点由 `battleRenderer.js` 绘制。王炸以项目原有大小王牌碰撞接连续两次爆破。观星按用户提供的 474 × 321 参考图取七星坐标：摇光 → 开阳 → 玉衡 → 天权 → 天玑 → 天璇 → 天枢，统一缩放并保持比例，仅连接六条相邻线，不添加斗口闭合线或外围法阵。

`audio/` 中的音效由网络授权素材剪辑混音，来源、作者、许可与改动见 [CREDITS.md](./CREDITS.md)。播放链路不再使用振荡器生成技能音效，台词仍使用项目原有语音。

本地预览：启动前端开发服务器后访问 `/dev/effects.html`，或 `/dev/effects.html?stage=1&controls=1` 直接预览牌桌。演出面板可选实时播放，或定格查看入场、蓄力、挥斩、冲击、收尾画面；铁骑的蓄力定格展示将军举戈待发，挥斩定格展示挥戈下令，冲击定格展示前倾冲锋；南蛮的蓄力定格展示抬脚举刀，冲击定格展示落脚完成。点清除或下一项即可结束定格，最长十分钟内自动清理。此入口不连接真实对局，也不在生产构建入口中，定格分支仅在开发模式启用。
