# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

## 手机布局与验证

页面通过 `src/layout/viewport.js` 测量 `visualViewport`，缺失时使用窗口尺寸；初始样式按 `100vh` → `100dvh` 回退。App 统一扣除四边安全区，页面与弹窗共用可见区域。双指缩放期间冻结布局尺寸，缩放回原比例后恢复测量。

牌桌采用信息区、操作栏、手牌区和独立工具栏。退出入口在左上方，剩余牌数在操作区右侧逐字纵向排列。手牌和对手牌背按各自容器宽度计算间距，手牌预留选牌抬升空间。短横屏的对手信息与锦囊展示共用按可用高度分配的布局。等待大厅横屏为完整看板娘保留独立列，竖屏将大幅上半身放在全宽玩家面板上方，四个座位紧凑排列，操作按钮紧随其后。结算立绘挂在边框右下角，返回按钮在面板内居中。极短横屏教学将任务说明放到侧边。空间不足时信息区、卡牌区或弹窗局部滚动；布局调整不修改游戏消息和对局状态。

验证命令（在本目录执行）：

```powershell
node --test tests/*.test.mjs
npm run build
# 先启动本地 Vite 服务；使用已有 Playwright 测试运行时，不添加业务依赖。
node tests/mobileLayout.browser.mjs
```

浏览器脚本默认使用 Chromium。PowerShell 可设置 `$env:LAYOUT_BROWSER = 'firefox'` 或 `'webkit'` 选择已有引擎；`PLAYWRIGHT_MODULE_PATH` 指向已有 Playwright 模块，`LAYOUT_BROWSER_PATH` 可指定浏览器可执行文件，`LAYOUT_URL` 可覆盖本地测试地址。脚本拦截 API 和 WebSocket，不连接真实对局。

验收覆盖 25 组视口：`320×480`、`360×640`、`390×660`、`430×740`、`568×240`、`667×280`、`768×390`、`844×280`、`479×640`、`480×640`、`767×390`、`1023×768`、`1024×768`、`1366×768`、`1440×900`、`393×852`、`852×393`、`956×440`、`667×375`、`375×667`、`440×956`、`480×320`、`640×360`、`660×390`、`740×430`。

联机大厅、普通牌桌、基础与进阶教学的对话和操作、详细规则、满员与空座位等待大厅、房间邀请/设置/好友抽屉、个人详情三个标签页、登录首页与登录/注册窗口均逐尺寸检查。五谷丰登、观星、万箭齐发、南蛮入侵、旁观与淘汰后旁观另在十一组代表尺寸检查；选将与胜负结算补查全部 25 组尺寸。还覆盖 1/8/14/16 张手牌、桌面牌和胜利牌、1/2/8/14/16 张对手牌背、多点实际点击位置、纵向牌数、看板娘裁剪与遮挡、局部滚动、安全区、模拟键盘区域、缩放、后台恢复、退出确认，以及旋转后选择和非心跳消息保持。

视觉验收同时检查：常见手机横屏锦囊高度至少 80px、完整的对手框不因锦囊响应而滚出顶部；横屏大厅使用横向背景，主要文字至少 14px，加入房间面板不占据大片空白；竖屏等待大厅的上半身立绘与紧凑玩家面板保持参考构图；结算立绘在右下框外完整可见，返回按钮居中且不被立绘遮挡。截图仍需人工检查构图和文字可读性，元素边界通过不能单独代表视觉通过。

登录首页使用与屏幕方向匹配的背景，横屏完整显示横版素材；快速开始和账号登录固定在安全区域底部，留出中间人物。竖屏联机大厅将导航与房间内容分区，房间行按两行排列，内容区可以上下滚动。选将卡片按说明内容确定高度，倒计时独立占位。胜利牌使用完整卡牌网格，牌多时仅牌区滚动；短横屏将胜者与牌区左右排列，标题和返回按钮保持可见，并为右下角看板娘预留空间。

每个引擎的截图和 `results.json` 写入 `temp-screenshots/mobile-acceptance/<引擎>/`。JSON 保存实际浏览器版本、时间、整体结果及各页面/状态的尺寸和截图路径；失败时保存诊断截图。代表演示包括 SE、16、Pro Max 和较小可见区域的手机横竖屏，以及两组桌面尺寸。

2026-10-11 已在 Windows 无头环境验证 Chromium 151.0.7922.10、Firefox 152.0.4、WebKit 26.5；浏览器用例使用系统回退字体和模拟 API/对局。构建及 132 项 Node 回归测试通过。

桌面浏览器模拟不能代替真机验收。发布前仍需在 iOS Safari/Chrome、Android Chrome、微信、QQ、UC 和厂商浏览器检查地址栏、刘海、输入法和后台恢复。
