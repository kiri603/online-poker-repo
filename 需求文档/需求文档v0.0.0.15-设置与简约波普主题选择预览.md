# 需求文档v0.0.0.15：设置与简约波普主题选择预览

## 1. 背景
用户要求将主页面声音入口改为“设置”，提供音乐、对话、音效控制，并保留原版，接入本轮简约波普方案。后续明确主题采用“选择＋预览”，不能选中即直接切换。简约波普登录页沿用用户之前制作的版本，可从本地读取素材。

## 2. 更新目标
- 主页面入口使用齿轮与“设置”名称。
- 集中显示音乐、对话、音效三个音量及百分比，提供静音与试听。
- 主题只有“原版”“简约波普”两个明确选项，展示当前使用状态。
- 选择只改变预览；玩家点击“使用此主题”后生效。关闭、取消、ESC 均不应用待选主题。
- 主题预览仅展示登录封面，可放大查看；封面不显示“开始游戏”“账号登录”等操作 UI。
- 简约波普登录使用本地 minimal.html 的已有设计，保留批准的小桃、手中卡牌、标题、剪影与构图。

## 5. 功能需求
### 设置入口
- 登录主页面与联机大厅提供设置；玩家在原版和简约波普中均能找到入口。
- 用统一设置组件承接声音与主题选择。
- 等待房间和对局的已有声音入口复用同一偏好，保留现有特效强度与署名入口。
- 设置打开不暂停服务器倒计时、不改变登录、房间或游戏状态。

### 声音
- 显示“音乐”“对话”“音效”，范围 0–100%，支持鼠标、触屏、方向键。
- 调整音量即时生效并保存至当前设备；不需要等待主题应用。
- 音乐控制现有 BGM；对话控制教程、报牌、技能等语音；音效控制洗牌、倒计时及战斗短音效。
- 保留全局静音，静音不覆盖各分类音量；恢复声音后使用原数值。
- 试听由玩家主动触发，同一时刻只播放一段，关闭设置/切到后台时停止试听。
- 已在播放的媒体与 WebAudio 增益同步变化，不仅下一次播放才生效。
- 对话为零或全局静音时，不阻塞教程字幕、继续操作、技能演出阶段或队列回调。
- 保留教程独立语音开关，它与全局声音共同决定教程声音是否播放。

### 主题选择与预览
- 使用单选形式，选项为“原版”“简约波普”。不使用二态切换开关，不点击选项就改变实际页面。
- 每个选项能识别风格，显示“当前”标记；选中状态与当前使用状态分开表达。
- 预览区只显示所选主题的登录封面，不展示大厅/账号分页，不显示开始和账号登录按钮。标题、背景、小桃与剪影保持可识别。预览不改变实际页面、主题偏好或业务状态。
- 提供放大查看，ESC 返回设置；预览内容没有真实登录、好友请求、房间连接等写入行为。
- 底部操作为“取消”“使用此主题”；所选主题已是当前主题时后者显示“当前使用”并禁用。
- 应用后保持当前页面、表单、登录态、房间及连接，不刷新页面、不重新登录。
- 真实游戏首次使用默认原版；保存后在 Auth 初始化前读取，刷新与退出登录后仍保持设备选择。
- 只允许已知主题值；存储损坏、被禁用或不可用时使用原版且页面继续可用。
- 主题只保存设备偏好，不与账号绑定，不修改认证、账号资料或数据库。
- 审核页继续以当前简约波普画面开始；审核偏好使用独立键，与真实游戏偏好隔离。

### 页面接入
- 原版保持当前背景、美术、信息与交互。新增设置属于本次授权改动。
- 简约波普登录沿用本地已制作方案，前景与手中卡牌保持原样，正式接入真实登录、注册、游客与验证码。
- 大厅以 v0.0.0.14 简化后的 A 桃色方案作为接入基准：墨字、房间入口、公开房间、必要帮助。B 墨色仍为审核备选，不增加第三个用户主题。
- 账号沿用简化后的账号、战绩、好友系统，保留必要数据、头像选择、统计口径、私聊与邀请风险提示。
- 全部真实接口字段、房间容量、权限及规则以现有业务实现为准，不能复制独立示例的样本数据。

## 6. 非功能需求
- 界面保持纯色、少量材质和稳定排版，不添加无关文字、重复容器、光晕或渐变；原版既有风格保持。
- 预览图缩放保持比例，不裁掉标题、人物脸部或主要操作。
- 无障碍单选、范围控件、清晰焦点；弹窗焦点约束、ESC、关闭后回到触发入口。
- 320px 手机到 1920px 桌面可操作；移动端允许设置正文纵向滚动，主要操作可达。
- 支持减少动态效果；登录原动效移植后检查中间帧、前后景错位与操作可用性。
- 素材本地打包，延迟加载放大图；主题选择不引入新的外部依赖或服务。
- 保持现有 Vue 模块拆分与编码；局部主题样式不得污染原版。
- 业务接入前按 AI_CODE_GUIDE 检查模板字段、store 一致性、移动端与 WebSocket 状态；静音不能取消必要的视觉演出回调。

## 8. 验收标准
1. 点主页面设置能看到三分类音量与当前主题。
2. 音量 0 / 中间值 / 100% 正常、各分类互不影响，刷新保留数值。
3. 选原版或简约波普只改变预览；关闭后实际主题保持。
4. 两种主题均显示纯登录封面，没有开始/账号登录操作；可放大，放大关闭回到设置，设置关闭回到入口。
5. 点击使用后应用并保存；刷新、退出登录后恢复；选择当前主题不重复应用。
6. 简约波普登录与上述本地方案一致，真实认证约束保持。
7. 原版能继续登录、进入房间、修改头像、查看战绩和好友；主题应用不产生额外业务请求。
8. 320×740、390×844、768×1024、1440×900、1920×1080、844×390 无横向溢出与无法关闭的弹窗。
9. 教程语音、报牌、倒计时、BGM、洗牌、战斗声音均验证即时音量；静音不改变字幕和玩法节奏。
10. 控制台无本次新增错误，前端构建通过。

## 9. 风险与注意事项
- 全局 CSS 和既有主题资源可能互相覆盖，必须通过根主题属性隔离并检查原版。
- 现有 audioManager 的 watch 更新 voice 与 BGM，倒计时和已播放的一次性音效需要确认是否同步增益。
- 教程音量为零时仍可能保持“语音正在播放”状态；正式接入需验证全文字幕和可继续操作。
- 登录材料是静态示例，不能沿用演示校验和假验证码。
- 浏览器自动播放限制与存储禁用需要正常降级；试听失败给出短提示。
- 应用主题不能销毁正在进行的对局组件、重连或丢失表单。
- 原版封面使用现有 Auth 背景与标题样式渲染；简约波普封面使用本地 minimal 原稿隐藏按钮后的独立渲染。主题预览统一不显示操作 UI，正式发布需保持素材与实际主题一致。
