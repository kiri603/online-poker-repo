# 需求文档v0.0.0.13：新手教学发布与服务器部署

## 1. 背景
新手教学、小桃台词、正式演出复用和高亮修正已完成，用户要求推送到远端并部署到服务器。

## 2. 更新目标
提交本次教学相关源码、测试与文档，推送 GitHub，并通过仓库现有 GitHub Actions 部署到服务器。确认对应提交部署成功及线上教学可用。

## 3. 任务类型与授权
版本发布与生产部署。用户明确要求“推送到远端，部署到服务器”，已授权本次提交、推送及执行现有部署流程。

## 4. 影响范围
本地 `codex/tutorial-release` 发布分支、`origin/main`、发布标签与发布说明；沿用 `.github/workflows/deploy.yml`。不修改部署脚本或服务器配置。

## 5. 功能需求
- 仅提交新手教学相关代码、测试、用户台词和需求记录，不提交本地 H2 数据库、临时截图、日志、依赖目录或构建产物。
- 本地基线 `08f5341b779f0e8269792494f51b5d9e8159e615` 已与远端 main 一致。提交按控制器／牌桌接入／发布记录拆分，推送 main 必须为快进，不覆盖远端历史。
- 以 `v0.1.0` 标记首次有标签的功能版本，并新增面向玩家的更新说明。该标签标识发布提交，不改动依赖版本。
- 推送 main 触发现有自动部署，等待该提交的构建、上传和远程替换步骤成功。
- 部署后检查首页、核心静态资源和后端读接口；在隔离浏览器中验证服务器提供的新教学界面与最新台词。

## 6. 非功能需求
保留所有未提交数据库改动和本地验证文件。复用已通过的 68 项测试、构建及四种视口验证，不重复无变化的本地检查。线上浏览器使用模拟身份与接口，避免创建正式账号、房间或战绩。

## 7. 不在本次范围
修改后端业务、数据库 schema、生产参数、凭据、认证权限、依赖版本或 CI 工作流。未要求新增服务、购买资源或通知其他人员。

## 8. 验收标准
远端 main 及发布标签指向发布提交，发布分支可追溯。对应 GitHub Actions 运行完成且成功；首页可访问、新资源可加载、后端读接口正常响应；线上完整六步教学结束获胜，显示用户最新小桃台词。本地数据库仍为未提交改动。

## 9. 风险与回滚
现有流程会备份前端、后端与数据库后替换并重启服务，部署期间可能短暂不可用。保留上一版提交 `08f5341`；若新版本不可用，优先通过仅撤销本次发布提交的普通回滚提交触发原流程重部署，不强推、不回滚服务器数据库。服务器既有 `/root/backup/` 为流程提供的旧版本备份。回滚前核对 main 未包含其他人的新提交，避免覆盖无关更新。

## 10. 验证计划
提交前核对暂存区文件和差异，确认未包含数据库、凭据或产物。复用同一代码状态的测试和构建结果；推送后查询对应提交的部署状态与任务步骤。部署后使用只读 HTTP 检查与隔离 Chrome 验证四种视口、13 页台词、完整教学、退出和重开；记录发布提交、运行链接和检查结果。
