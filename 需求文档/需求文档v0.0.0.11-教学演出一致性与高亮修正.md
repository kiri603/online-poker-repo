# 需求文档v0.0.0.11：教学演出一致性与高亮修正

## 1. 背景
用户反馈教学中的“习”字装饰不需要；制衡等动作的演出与正式牌局不同；时间显示应使用无穷大符号；折叠手牌的聚光范围会照亮邻牌。用户要求提供现有各阶段台词供修改。

## 2. 更新目标
去掉教学顶部及退出确认中的“习”字图标。教学复用正式牌局的特效层、动作反馈、特效质量偏好和音效。时间区域沿用正式倒计时外观，数值显示 ∞。讲解与操作高亮只覆盖目标牌的可见区域。交付完整台词原文。

## 3. 任务类型
问题修复与教学界面调整。用户本轮明确要求修改，并追加去掉顶部“习”字，已授权本轮范围，无需重复确认。

## 4. 影响范围
教学页、聚光组件、教学会话适配、GameBoard、正式特效会话绑定及相关测试。保持现有正式特效公开入口兼容。保留此前未提交教学实现及本地数据库文件改动。

## 5. 功能需求
- 去掉顶部标识与退出确认内的“习”字及空图标占位。
- 使用正式 GameBoard 倒计时 UI，显示 ∞，不再显示“教学不限时”标签；教学仍无超时自动动作。
- 制衡使用正式 PLAYER_REPLACED 演出与“制衡”飘字、语音，过牌使用“要不起”飘字与语音，出牌使用正式牌型演出和音效，获胜使用现有胜利音乐。
- 特效组件和演出逻辑共用，教学的特效列表、去重器及延迟回调独立，不写正式对局状态、不经过 WebSocket。
- 动作演出完成后才进入下一段讲解，避免制衡、顺子特效被讲解遮罩截断。退出、重开与后台清理教学演出，取消待执行动作。
- 聚光依据卡牌实际叠放顺序和可见矩形裁剪，不能照亮高层邻牌。操作阶段沿用折叠手牌，用同一几何计算绘制目标描边，选齐后仅高亮动作按钮。
- 提供邀请、六阶段对白、任务条、结业与退出确认的当前文本，供用户编辑；本轮不自行改写对白。

## 6. 非功能需求
保持红金主题、键盘操作和桌面、手机横竖屏适配。新会话绑定可选，正式牌局默认行为一致；保留减少动态效果和完整／轻量特效偏好。文字与文档使用 UTF-8。

## 7. 不在本次范围
修改教学牌序、动作限制、邀请策略、规则逻辑、真实房间、后端、数据库、认证权限、依赖版本或生产配置。

## 8. 验收标准
教学与退出确认不出现“习”字装饰；时间使用正式计时器外观显示 ∞。制衡、普通出牌与顺子的特效和正式会话使用相同演出类型、时长和资源。正式、教学特效状态互不影响。第一张 3 高亮不照亮两张 4，对子高亮不照亮左右邻牌，选牌与取消后描边跟随目标可见区域。完整六步仍得出 0／6／13 张。退出、重开、后台与确认弹窗不造成脚本跳步。台词导出与源码原文一致。

## 9. 风险与注意事项
特效层目前绑定全局状态，应改为可选会话来源，并保留既有正式入口。高亮必须考虑遮挡而不只使用整张牌的外接矩形；邻牌抬起、屏幕旋转和尺寸变化后需重算。保护本地 poker/data/poker-auth.mv.db 及原有未提交改动，不做真实账号或房间写入测试。

## 10. 测试计划
先增加会话隔离、演出一致性、特效完成后推进、几何裁剪与取消回调测试，确认失败后修复。使用隔离 Chrome 和模拟接口验证六步、制衡与顺子演出、高亮、退出与正式牌桌前端回归。验证 1440×900、390×844、844×390、320×568 视口。执行 node --test tests/*.test.mjs、npm run build、git diff --check。评估并记录高亮错误模式至 AI_CODE_GUIDE.md。后端本轮不变，不执行迁移或数据库写入。

- 聚光和操作描边共用可见区域裁剪；选牌动画、重算和卸载回调均有清理。
- 当前台词原文交付至 `需求文档/新手教学台词-小桃.md`，对白未改写。
